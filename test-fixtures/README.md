# Fixture XCursos

`xcursos-real.htm` é derivado do HTML real fornecido para regressão do parser. Antes do empacotamento, parâmetros de URL assinada R2 foram substituídos por valores fictícios (`REDACTED`). A estrutura necessária para validar curso, aula, posição, MP4 assinado, materiais e sidebar foi preservada.
