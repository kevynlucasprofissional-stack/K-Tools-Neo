# Engineering Journal

## Purpose

Durable investigation memory and anti-repetition protocol for K-Tools Neo.

## Read-before-work rule

Before investigating or modifying an area, search `CURRENT.md` and later archives for component names, fingerprints, hypotheses, runtimes and decisions.

## Write rule

Record material hypotheses, refutations, causes, evidence boundaries, reusable probes, architectural lessons and decisions whose loss would cause repeated work.

## Anti-repeat rule

Do not repeat a conclusive experiment unless a material version, environment, boundary, code path or evidence requirement changed; record what changed.

## Evidence rule

Differentiate unit, contract, integration, native and E2E evidence. Never promote a weaker class by narrative.

## Secrets rule

Never persist tokens, credentials, cookies or sensitive payloads.
